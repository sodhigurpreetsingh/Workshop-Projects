# AI Quiz Generator

A Vue.js 3 frontend for the AI-powered MCQ Quiz Generator. Enter any topic or paste study notes and get multiple-choice questions with answers and explanations — instantly.

---

## Features

- **Topic or Notes Input** — type a subject name or paste full study notes
- **Question Count** — choose 3 to 10 questions
- **Difficulty Control** — Easy, Medium, or Hard
- **Instant MCQs** — four options per question, generated by GPT-4o-mini
- **Answer & Explanation** — reveals the correct answer and a clear explanation after each attempt
- **Score Summary** — colour-coded final score card (green / amber / red)
- **Example Topics** — one-click chips to pre-fill the topic field

---

## Prerequisites

- **Node.js 16+** — [nodejs.org](https://nodejs.org/)
- **Backend API** running on `http://127.0.0.1:8000` — see [../backend/README.md](../backend/README.md)

---

## Installation & Running

```bash
cd quiz-generator
npm install
npm run dev
```

App runs at **http://localhost:5173**

---

## API

Connects to the shared FastAPI backend:

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/v1/quiz/generate` | Generate MCQ questions |
| `GET`  | `/api/v1/quiz/health`   | Health check |

**Request body:**
```json
{
  "topic": "Python functions and loops",
  "num_questions": 5,
  "difficulty": "Medium"
}
```

**Response:**
```json
{
  "success": true,
  "questions": [
    {
      "question": "What keyword defines a function in Python?",
      "options": { "A": "func", "B": "def", "C": "define", "D": "function" },
      "answer": "B",
      "explanation": "The def keyword is used to declare a function in Python."
    }
  ],
  "metadata": { "num_questions": 5, "difficulty": "Medium", "execution_time_ms": 2100 }
}
```

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Cannot connect to backend | Ensure backend is running: `http://127.0.0.1:8000/api/v1/quiz/health` |
| No questions returned | Check OpenAI API key in `backend/.env` |
| Port already in use | Vite will auto-increment — check terminal for the actual URL |
